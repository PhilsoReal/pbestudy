# PBE Study

PBE Study is a mobile-friendly Pathfinder Bible Experience training platform. The 2026/27 pilot is being used by Oxford Academics Pathfinder Club.

Website: https://pbestudy.com

## Deployment

This repository is configured for GitHub Pages. The site entry point is `index.html` and the custom domain is declared in `CNAME`.

## Current pilot scope

Mark, 1 John, 2 John, 3 John, 1 Peter and 2 Peter.
